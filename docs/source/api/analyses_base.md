# Analysis Base Classes

API reference for `polyzymd.analyses.base`, including the plugin base class,
context objects, and shared comparison/result models. A plugin imports
`Analysis`, `MetricValue`, and lifecycle contexts from this module rather than
from private implementation modules. No shipped analysis is a plugin any more,
and the plugin framework is being removed.
